# VK Chat-Bot «Алина» на базе GigaChat

Консультант онлайн-университета **Zerocoder** в сообществе ВКонтакте. Бот слушает
сообщения, которые пишут пользователи сообществу, и автоматически отвечает на них
с помощью нейросети **GigaChat** (Sber). Отвечает только по темам университета:
курсы, программы, форматы обучения, выбор направления.

## Возможности

- Принимает сообщения сообщества через **Long Poll API** ВКонтакте (`VkLongPoll`).
- Генерирует ответы через **GigaChat API** (`POST /v2/chat/completions`).
- Держит **контекст диалога** — запоминает последние 20 сообщений каждого пользователя.
- Работает от имени **Алины** с подробным системным промптом и базой знаний Zerocoder.
- Показывает статус **«печатает...»** и не падает на ошибках обработки одного сообщения.
- Плавно обрезает длинные ответы под лимит сообщений ВКонтакте (4000 символов).
- Автоматически обновляет OAuth-токен GigaChat (действует 30 минут).
- Все секреты — только в переменных окружения, код не содержит реальных ключей.

## Архитектура и как это работает

1. `bot.py` подключается к сообществу через Long Poll API и ждёт новые сообщения.
2. На каждое сообщение собирается запрос для модели: системный промпт Алины +
   история диалога + новое сообщение пользователя.
3. `gigachat_client.py` получает `access_token` по OAuth 2.0
   (`POST https://ngw.devices.sberbank.ru:9443/api/v2/oauth`, токен живёт 30 минут
   и обновляется автоматически) и вызывает `POST https://api.giga.chat/v2/chat/completions`.
   Специфика версии API `v2` учтена: поле `content` сообщений — массив объектов.
4. Ответ Алины отправляется в VK, сообщения добавляются в историю диалога.

## Установка и запуск

### 1. Клонирование

```bash
git clone https://github.com/bojulka2-ship-it/vk-gigachat-bot.git
cd vk-gigachat-bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Скопируйте образец и заполните реальные значения:

```bash
cp .env.example .env
```

### 4. Запуск

```bash
python bot.py
```

Напишите боту в сообщения сообщества — он ответит от имени Алины.

## Переменные окружения

| Переменная | Обязательна | Что это и где взять |
|---|---|---|
| `VK_GROUP_TOKEN` | да | **Токен доступа сообщества ВКонтакте.** Сообщество → **Управление** → **Работа с API** → **Ключи доступа** → «Создать ключ». Включите право **«Сообщения сообщества»**. |
| `VK_GROUP_ID` | нет | ID сообщества ВКонтакте (без минуса). |
| `GIGACHAT_CLIENT_ID` | нет | Client ID проекта GigaChat API. [developers.sber.ru](https://developers.sber.ru) → **Studio** → **GigaChat API** → «Генерация ключа авторизации». |
| `GIGACHAT_CLIENT_SECRET` | да | Client Secret — выдаётся там же, где Client ID. |
| `GIGACHAT_SCOPE` | нет | `GIGACHAT_API_PERS` — для физлиц (бесплатные 60 запросов/сутки), `GIGACHAT_API_CORP` — для ИП/юрлиц. |
| `GIGACHAT_MODEL` | нет | Модель: `GigaChat-2`, `GigaChat-2-Pro`, `GigaChat-2-Max`, `GigaChat-3-Ultra`. По умолчанию `GigaChat-2-Max`. |
| `GIGACHAT_VERIFY_SSL_CERTS` | нет | Проверка SSL-сертификатов НУЦ Минцифры: `true`/`false`. По умолчанию `false`. |

> Если есть только один ключ авторизации без отдельного Client ID — оставьте
> `GIGACHAT_CLIENT_ID` пустым, код попробует авторизоваться одним секретом.

## Безопасность

- **Никогда не публикуйте `.env`** — там лежат рабочие ключи. Файл уже добавлен в `.gitignore`.
- **Не вписывайте ключи в код.** Все секреты читаются из переменных окружения в момент запуска.
- Если случайно закоммитили `.env` — удалите его из Git (`git rm --cached .env`),
  отзовите и пересоздайте ключи на стороне VK и GigaChat.

## Возможные проблемы

| Проблема | Решение |
|---|---|
| `Не задан VK_GROUP_TOKEN` | Заполните `.env` в корне проекта. |
| `401 Unauthorized` от GigaChat | Проверьте Client ID / Client Secret, срок действия ключа. |
| «GigaChat API временно недоступен» | Проверьте `GIGACHAT_SCOPE` и баланс токенов в Studio, попробуйте `GIGACHAT_VERIFY_SSL_CERTS=false`. |
| Бот не видит сообщения VK | Проверьте право «Сообщения сообщества» у токена и включённый Long Poll API. |
